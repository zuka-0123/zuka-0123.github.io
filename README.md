# 余白のノート — GitHub Pages ブログ

GitHub Pages と Jekyll で動く、日本語ブログのテンプレートです。記事は Markdown ファイルを追加するだけで公開できます。

## 記事を書く（いちばん簡単な方法）

1. GitHubのリポジトリで **Issues** を開く
2. **New issue** → **新しい記事を書く** を選ぶ
3. タイトル、本文、必要ならタグを入力して送信する
4. 数分後、自動でブログに公開される

投稿時にファイル名や日付、特別な設定を書く必要はありません。

## GitHub Pages で公開する（初回のみ）

1. GitHub で `zuka-0123.github.io` という公開リポジトリを作る
2. このフォルダの中身をリポジトリへアップロードする
3. リポジトリの **Settings → Pages** を開く
4. **Source** を `Deploy from a branch`、ブランチを `main`、フォルダを `/(root)` にして保存する
5. 数分後、`https://zuka-0123.github.io/` で公開される

別名のリポジトリで公開する場合は、`_config.yml` の `baseurl` を `/リポジトリ名` にしてください。

## 新しい記事を書く

`_posts` に `YYYY-MM-DD-半角英数字の名前.md` を作ります。

```markdown
---
title: 記事のタイトル
date: 2026-08-11 20:00:00 +0900
tags: [数学, 日記]
---

一覧に表示する短い導入文を書きます。

<!--more-->

ここから記事の続きです。Markdownで自由に書けます。
```

## 手元で確認する（任意）

Ruby と Bundler が入っている環境で次を実行します。

```text
bundle install
bundle exec jekyll serve
```

表示された `http://localhost:4000` をブラウザで開きます。

## 含まれるページ

- 最新10件を表示するホーム
- キーワード検索付きアーカイブ
- 件数付きタグ一覧
- プロフィール用 About ページ
- 記事の前後リンク、タグ
- RSS、SEO、サイトマップ
- ライト／ダークモード自動対応
- スマートフォン向けメニュー
